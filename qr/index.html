URLを変えたときの作り直し手順
  1. assets/js/profile-config.js の siteUrl を新しい公開URLに書き換える
  2. 下のコマンドを実行する（4ファイルが同時に更新されます）
  3. 変更をコミットして push する
pip install segno
python3 tools/gen_qr.py
# URLを直接指定したい場合
python3 tools/gen_qr.py --url https://your-domain.example/

QRはURLだけを埋め込んでいます。サイト側の中身をいくら更新してもQRは刷り直し不要です。 逆にURLが変わるとQRは無効になるので、独自ドメインを使う予定があるなら先にドメインを決めてから印刷してください。
